# movie-explorer
The goal of this project is to implement the web application called movie-explorer which allows users to search for movies by name using OMDb API.It displays important details such as movie poster,title and release year.Users can also add to watchlist or remove them from watchlist after watching it.


## Features
-Search movies by name
-Display movie details like movie-poster,title and release year
-Filter or sort results
-Responsive design 
-Add or remove movies from watchlist


## Techstack
Techstack used in this application are
-HTML
-CSS
-Javascript.


## API
API used in this application is OMDb API.

## How to run
1. Clone the respository.
2. Open index.html in your web browser.
